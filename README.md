# KBO Stats+ | 세이버메트릭스 대시보드

> KBO 1982~2025년, 44시즌의 세이버메트릭스 지표를 MLB 공개 계산식으로 직접 산출한 대시보드입니다.

---

## 1. 프로젝트 배경 — 왜 만들었는가

### 문제 상황

2024년 스탯티즈(Statiz) 개편 이후, KBO 세이버메트릭스 수치 계산에 관한 논란이 지속되고 있습니다.

- **계산 기준의 불투명성**: 주요 세이버메트릭스 사이트들이 자체적으로 수치를 산출하지만, 계산 과정이 완전히 공개되지 않아 같은 선수의 같은 시즌에 대해 사이트마다 다른 수치가 나오는 경우가 있습니다.
- **관계자와 팬의 혼동**: 이러한 수치 차이는 프로팀 프런트 관계자는 물론, 데이터를 참고하는 팬들에게도 혼동을 일으킵니다. "이 선수의 wRC+가 도대체 얼마가 맞는 거야?"라는 질문이 커뮤니티에서 반복됩니다.
- **검증 가능성의 부재**: 계산 과정이 비공개이므로 제3자가 결과를 검증하거나 재현할 수 없습니다.

### 해결 방향

이 프로젝트는 **MLB에서 검증되고 공개된 계산식**(FanGraphs, Baseball-Reference, Tom Tango)을 그대로 KBO 데이터에 적용하여 세이버메트릭스 지표를 재작성합니다.

- 모든 계산식은 이 문서에 공개됩니다.
- 원본 데이터는 KBO 공식홈페이지에서 수집합니다.
- 누구든 같은 데이터와 같은 공식을 적용하면 동일한 결과를 얻을 수 있습니다.

```
- 외부 사이트의 계산된 세이버 수치는 참조하지 않음
```

## 4. 이용한 계산식

모든 계산식은 MLB에서 공개·검증된 공식을 기반으로 하며, KBO 리그 환경(DH 제도, 연도별 경기수, 팀 수)에 맞게 조정했습니다.

### 4-1. 파크팩터 (Park Factor)

> 특정 구장이 득점에 미치는 영향. 100이 중립.

```
PF = H × T / ((T-1) × R + H)
```
- H = 홈 경기 양팀 합산 RPG (타격R + 투수R) / 홈 경기수
- R = 원정 경기 양팀 합산 RPG / 원정 경기수
- T = 해당 연도 리그 팀 수 (6~10, 연도별 다름)
- 출처: FanGraphs "Park Factors"

### 4-2. ERA+ (보정 평균자책점)

> 투수의 ERA를 리그 평균과 파크팩터로 보정. 100이 리그 평균.

```
ERA+ = 100 × (lgERA / ERA) × (PF / 100)
```
- lgERA = 해당 연도 리그 전체 평균 ERA
- PF = 해당 투수 소속팀의 파크팩터
- 규정이닝: 팀 최대 경기수 × 1.0
- 출처: Wikipedia "Adjusted ERA+", FanGraphs Sabermetrics Library

### 4-3. OPS+ (보정 OPS)

> 타자의 OPS를 리그 평균과 파크팩터로 보정. 100이 리그 평균.

```
OPS+ = 100 × (OBP/lgOBP + SLG/lgSLG - 1) / (PF/100)
```
- lgOBP, lgSLG = 해당 연도 리그 전체 합산으로 계산
- 출처: Baseball-Reference

### 4-4. wOBA (가중 출루율)

> 각 타격 이벤트에 득점 기여 가중치를 부여한 출루율.

```
wOBA = (wBB×BB + wHBP×HBP + w1B×1B + w2B×2B + w3B×3B + wHR×HR)
       / (AB + BB - IBB + SF + HBP)
```

| 이벤트 | 가중치 |
|---|---|
| BB (고의사구 제외) | 0.69 |
| HBP | 0.72 |
| 1B (단타) | 0.89 |
| 2B (2루타) | 1.27 |
| 3B (3루타) | 1.62 |
| HR (홈런) | 2.10 |

- 현재: Tom Tango 기본 가중치 사용 (고정값)
- 향후: KBO 리그 환경에 맞춘 연도별 가중치 재계산 예정
- 출처: Tom Tango, "The Book: Playing the Percentages in Baseball"

### 4-5. wRC+ (보정 득점 생산)

> wOBA를 파크팩터와 리그 환경으로 보정한 종합 타격 지표. 100이 리그 평균.

```
wRC+ = (((wRAA/PA + lgR/PA) + (lgR/PA - PF × lgR/PA)) / (lgR/PA)) × 100
```
- wRAA = ((wOBA - lgwOBA) / wOBA_Scale) × PA
- wOBA_Scale ≈ lgwOBA / lgOBP
- 출처: FanGraphs "wRC and wRC+"

### 4-6. Proxy WAR (근사 대체선수 대비 승리 기여)

> ⚠️ 이 지표는 수비(UZR)와 비도루 주루(UBR)를 포함하지 않은 **근사값**입니다.

**타자:**
```
Proxy WAR = (Batting Runs + wSB + Positional Adj + League Adj + Replacement Runs) / RPW
```
- Batting Runs = wRAA + 파크팩터 보정
- wSB = SB × 0.2 + CS × (-(2 × RunsPerOut + 0.075))
- Positional Adj = 포지션별 고정값 × (수비이닝/시즌이닝) × (KBO경기수/162)
- RPW = 9 × (lgR/lgIP) × 1.5 + 3
- 출처: FanGraphs fWAR (포지션 보정값), kbo_proxy_war_spec.md

**투수 (RA9 기반 bWAR 방식):**
```
Proxy WAR = (Replacement RA9 - PF보정 RA9) × IP/9 / RPW
```
- RA9 = (실점 × 9) / 이닝 (비자책점 포함)
- Replacement RA9 = lgRA9 × 1.35
- 출처: Baseball-Reference bWAR

**포지션 보정값 (런 / 162경기 기준, FanGraphs 표준):**

| 포지션 | 보정값 |
|---|---|
| 포수 | +12.5 |
| 유격수 | +7.5 |
| 2루수 / 3루수 / 중견수 | +2.5 |
| 좌익수 / 우익수 | -7.5 |
| 1루수 | -12.5 |
| 지명타자 | -17.5 |

**KBO 연도별 정규시즌 경기수:**

| 기간 | 경기수 |
|---|---|
| 1982 | 80 |
| 1983~1984 | 100 |
| 1985 | 110 |
| 1986~1988 | 108 |
| 1989~1990 | 120 |
| 1991~1998 | 126 |
| 1999 | 132 |
| 2000~2004 | 133 |
| 2005~2008 | 126 |
| 2009~2012 | 133 |
| 2013~2014 | 128 |
| 2015~2025 | 144 |

### 4-7. FA 적정가 모델

**가중 WAR 산출:**
```
가중 WAR = FA시즌 WAR × 0.70 + 직전시즌 WAR × 0.20 + 직전5년 평균 WAR × 0.10
```

**WAR당 가격 계수 (과거 344건 FA 계약에서 도출):**

| 구분 | 값 |
|---|---|
| 최근(2022~) 평균 | 5.92억/WAR |
| 전체 평균 | 4.54억/WAR |
| 중앙값 | 1.99억/WAR |

**적정 연봉 범위:**
```
Low  = 가중WAR × 중앙값 × 0.8
Mid  = 가중WAR × 최근평균
High = 가중WAR × 최근평균 × 1.3
```

**등급:**

| 가중 WAR | 등급 | 설명 |
|---|---|---|
| 6 이상 | S | MVP급 |
| 4 이상 | A | 올스타급 |
| 2 이상 | B | 주전급 |
| 1 이상 | C | 백업급 |
| 1 미만 | D | 대체선수 수준 |

**검증**: 2026 FA 실제 계약 6건 중 5건(83%)이 모델 추정 범위 내에 포함.

## 5. 사용자 경험 — 이 대시보드가 전달하고자 하는 것

### 프로팀 관계자와 데이터 분석 팬에게

**신뢰할 수 있는 데이터를 제공합니다.**

기존 세이버메트릭스 사이트 간의 수치 차이로 인한 혼동을 줄이기 위해, MLB에서 검증된 공개 계산식을 그대로 적용했습니다. 모든 공식은 이 문서에 명시되어 있으며, 원본 데이터(KBO 공식홈페이지)와 계산 과정을 누구나 검증할 수 있습니다. 같은 공식, 같은 데이터를 넣으면 같은 결과가 나옵니다.

### 야구를 처음 접하는 사람에게

**지표 설명으로 야구에 친근감을 줍니다.**

"wRC+가 뭐야?", "ERA+가 높으면 좋은 거야?" 같은 질문에 답하는 용어집(글로서리)을 제공합니다. 각 지표의 의미, 계산법, 해석 기준을 쉬운 말로 설명하여 세이버메트릭스가 어렵게 느껴지는 팬도 자연스럽게 데이터 야구에 접근할 수 있도록 했습니다.

### 기존에 야구를 아는 사람에게

**더 깊이 즐길 수 있는 도구를 제공합니다.**

44시즌 전 연도 데이터를 한 곳에서 비교할 수 있고, FA 적정가 모델로 스토브리그의 계약을 데이터 관점에서 분석할 수 있습니다. "이 선수의 계약이 오버페이인가?"라는 질문에 성적 기반 근거를 제시합니다. 1982년 백인천부터 2025년 송성문까지, KBO 역사를 관통하는 데이터 여행을 경험할 수 있습니다.

## 6. 한계 및 Disclaimer

이 프로젝트는 공개 데이터와 검증된 공식만을 사용하지만, 몇 가지 구조적 한계가 있습니다.

| 한계 | 설명 | 대응 |
|---|---|---|
| **Proxy WAR ≠ fWAR/bWAR** | 수비(UZR)와 비도루 주루(UBR)를 포함하지 않습니다. 영상 추적 데이터가 공개되지 않아 계산 불가능합니다. | 대시보드에 "Proxy WAR (수비 제외)"로 명시 |
| **wOBA 가중치 고정** | 현재 Tom Tango 기본 가중치를 전 연도에 동일 적용합니다. 실제로는 리그 득점 환경에 따라 연도별로 달라져야 합니다. | 향후 KBO 연도별 가중치 재계산 예정 |
| **수비/주루 데이터 제한** | 2001년 이전 수비이닝/도루 데이터가 없어 1982~2000 Proxy WAR은 정밀도가 낮습니다. | 포지션 보정을 DH로 가정 |
| **FA 모델 한계** | 성적(WAR) 기반만 반영합니다. 팀 니즈, 시장 희소성, 마케팅 가치, 나이(aging curve), 모기업 재정 상황 등 비경제적 요인은 반영되지 않습니다. | "성적 기반 추정이며 실제 계약과 차이가 있을 수 있습니다" 명시 |
| **투수 역할 판정** | GS(선발등판) 데이터 없이 SV/HLD/W/IP 기반으로 추정합니다. 일부 선수가 선발↔불펜으로 오분류될 수 있습니다. | 향후 GS 데이터 확보 시 개선 |

## 8. 기여 및 피드백

이 프로젝트는 개인 프로젝트이며, 데이터의 정확성과 계산의 신뢰성을 높이기 위한 피드백을 환영합니다.

- **수치 오류 제보**: 특정 선수/연도의 수치가 이상한 경우
